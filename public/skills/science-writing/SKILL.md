# 科普写作

将学术知识转译为**通俗、可信、让人记得住**的科普文章。

科普写作有三个核心要素：

- **真实与通俗**：学术内容不能原样搬运，必须转译为读者能理解的语言。
- **可记忆性**：读者读完应有收获，而非水过鸭背。
- **概念忠实**：通俗化不能以牺牲因果机制和模型自觉为代价。

科普写作中有一个系统性陷阱：**修辞对概念的殖民**——拟人化替换因果机制，比喻替换物理图像，故事替换历史证据，目的论替换动力学解释，文学升华替换模型自觉。本技能全程设防，准则见 `references/rhetoric-discipline.md`（8 条，写作全程参照，Phase 3/4/5 必查）。

---

## 工作流程

1. Phase 1 选题与需求理解
2. Phase 2 文献检索与素材收集
3. Phase 3 术语转译与初稿撰写
4. Phase 4 润色与记忆点强化
5. Phase 5 自查与交付
6. Phase 6 终稿精修

> **双重防线说明**：Phase 4 的"修辞纪律"是**写作期**护栏（动笔时遵守），Phase 5 第 6–13 项是**核查期**对同一些纪律的逐条复验。二者内容看似重叠，实则是"写时守、写后查"的两道关，不是冗余。

---

## 交互与自主模式

- **有人交互时**：Phase 1 向用户确认需求；Phase 3 初稿完成后暂停，请用户确认方向再进入润色（见各 Phase 的"暂停点"）。
- **无人交互 / 自主模式时**（如由 agent 直接执行）：用下列默认值代入并一气呵成产出**终稿 + QA 自检报告**，不中途停顿：
  - 目标读者 = 受过基础科学教育的普通成年人（懂中学物理化学，但不熟悉该细分领域）
  - 篇幅 = 中等（1500–4000 字）
  - 素材 = 自行检索权威信源
  - 交付 = 单篇终稿 + 一份按 Phase 5 模板填写的 QA 报告

## Phase 1：选题与需求理解

明确写作目标。向用户确认以下信息（自主模式用默认值）：

- **主题**：用户想科普什么？已有明确选题，还是需要帮忙选题？
- **目标读者**：写给谁看？决定通俗化程度。按三档校准：
  - *大众*：几乎无专业背景，需更多比喻与背景铺垫，避免公式。
  - *爱好者*（默认）：有中学以上科学素养，可保留部分术语与简化公式。
  - *专业读者*：同领域但非专家，可深入机制，术语可不逐条注音。

**题材类型与结构适配**（迭代新增）：六阶段流程通用，但不同题材的开头与骨架应不同，避免都写成"首先/其次"的说明书。按选题归属选一种骨架：

| 题材类型 | 典型开头 | 推荐骨架 |
|---|---|---|
| 原理解释型 | 先抛一个**常见误读**当"坑" | 误读钩子 → 精确机制 → 显式堵漏（与"误区纠正型"可合并） |
| 误区纠正型 | 先亮**普遍误解** | 误解呈现 → 给判据/数据 → 重构认知，结尾点明"错在哪一层" |
| 历史叙事型 | 可用轶事作钩子，但**须前置标注"此为流传说法，史料存疑"** | 史实与轶事分离 → 机制 → 回扣；**钩子用后须显式降级：轶事≠机制，点明"钩子是引子，答案在机制"**，不得让轶事暗中承担因果 |
| 机制拆解型 | 现象/反直觉锚点 | 现象锚点 → 逐层因果 → 反直觉转折收束 |
| 统计/数据解读型 | 先亮**普遍误读**（常是相对/绝对、群体/个体混淆） | 误读呈现 → 给区间/基线/群体≠个体 → 重构，点明"错在哪一层" |

> 一篇文章可混合两类骨架，但**主线只能有一条**；选错骨架（如把原理解释写成历史八卦）是最常见的结构翻车。

- **篇幅预期**：短文（≤1500 字）、中等（1500–4000 字，默认）、长文（>4000 字）。
- **素材情况**：用户是否已有参考论文/资料？还是需要从头检索？

若用户只给了模糊方向，主动提出 **2–3 个**具体选题建议供选择，每个选题附带简要的科普角度说明。

**暂停点**：确认需求后再进入 Phase 2。

## Phase 2：文献检索与素材收集

**信源优先级**（从高到低）：

1. 一手学术文献（期刊论文、预印本）
2. 权威学术期刊的综述文章
3. 权威媒体的深度报道（如 Nature News、Scientific American、主流媒体的科学版）
4. 一般媒体报道（仅作为"现象存在"的佐证，不作为核心论据）

**信源黑名单**（以下来源一律不作为信源使用）：

- 微信公众号、百家号、今日头条、搜狐号、网易号等自媒体聚合平台内容
- 缺乏作者署名或无编辑审核机制的转载站
- 问答类平台（百度知道、知乎回答等）的 UGC 内容
- SEO 农场与内容农场站点

这些平台内容未经同行评审或专业编辑审核，事实错误率高，且常互相转载导致错误循环放大。即便出现在搜索结果中也不采信。

**操作要点**：

- 用 search 工具检索学术论文与权威资料，优先学术来源；结果质量差时换英文关键词检索国际学术源。
- 出现黑名单信源时跳过不取；若搜索结果主要由黑名单信源构成，更换搜索词或限定来源（如 `site:.edu`、`site:nature.com`）重新检索。
- 收集到的关键事实记录出处（论文标题/期刊/年份，或报道标题/媒体/日期）。
- 事实性陈述必须有出处；不确定的信息标注"有待查证"，而非模糊带过。
- **检索边界**：单主题检索上限约 3–4 轮；若仍只有黑名单信源，判定为"信源不足"，将相关论断明确标注为"有待查证"后再行文，不得假装确凿。
- 收集完毕后，将素材整理为简明要点清单，向用户展示核心素材，确认无遗漏再进入写作（自主模式：直接展示于 QA 报告"素材清单"一节）。

## Phase 3：术语转译与初稿撰写

这是最核心的环节——将学术语言转化为通俗语言，同时不丢失准确性。

### 转译原则

1. **术语剥离**：将专业术语替换为日常语言。替换后检查核心观点是否依然准确成立——若替换后内容变空洞，说明理解还不够深，需重写而非回退到术语。
2. **比喻管控**：用读者熟悉的事物类比，帮助理解抽象概念。约束见 `references/rhetoric-discipline.md`：
   - 一个核心概念全程只用一个比喻体系，不堆叠不兼容的比喻；
   - 比喻必须标注其失效边界——在何处类比成立，在何处失灵；
   - 找不到不歪曲物理图像的比喻时，宁可不用比喻，用直白因果描述替代。
3. **逻辑铺陈**：概念出场要有前因后果，先给读者"为什么现在要提这个"的理由。层层递进，让结论水到渠成。
4. **增量推进**：每句话提供新信息。上一句说"是什么"，下一句说"为什么重要"或"意味着什么"。避免同义反复。
5. **去拟人化**：不把粒子、分子或物理系统写成有意图的主体。不说"电子选择了""原子想要"，而说"在某某条件下，电子呈现某某分布"。因果机制用约束和条件描述，不把数学结果倒装为动机。
6. **模型自觉**：理论模型是表征工具，不是物理实在。描述时让读者知道这是"我们用来解释现象的框架"，而非"原子内部真实发生的过程"。

### 操作演示： colonized → 纪律化

> 下面用**占位符**展示"修辞殖民 → 纪律化"的**形式逻辑**（不绑定任何具体题材，避免把领域知识写死在技能里）。实际写作时把【括号】换成你的概念即可。

| 失守类型 | ❌ 被殖民的写法（淘汰，形式） | ✅ 纪律化改写（形式） |
|---|---|---|
| 拟人化 | "【某系统】**想要**【X】，于是【Y】。" | "在【条件 C】下，【系统】呈现【状态 S】——用约束与条件描述，不把结果倒装为动机。" |
| 目的论 | "【A】**为了**【B】，所以【C】。" | "在【条件 C】下，【C】是约束下的唯一可能结果，而非为【B】服务的意图。" |
| 比喻堆叠 | "【概念】既像【比喻甲】，又像【比喻乙】……" | "用**单一**比喻体系描述【概念】；在【范围】内成立，在【范围】外失灵（标失效边界）。" |
| 模型实体化 | "【模型 M】让【对象】内部'装修'出【结构】。" | "我们用【模型 M】这一数学/表征框架描述【现象】；它是便捷工具，并非【对象】内部真实发生的过程。" |

### 结构原则

- **主次分明**：动笔前划定核心论点（详写，占 60% 以上篇幅）与辅助论点（略写）。
- **有机组织**：结构服从内容，不追求形式对称。拒绝"首先/其次/最后"这类万能模板。
- **扁平结构**：层级最多两层，标题简短（建议 ≤12 字），不使用序号堆砌。
- **闭环论证**：开头提出的问题，结尾必须回应。前面挖的"坑"后面要填上。

### 符号与排版规范

科普文章不可避免地出现化学式、物理量和数学表达式，排版必须统一、准确。

1. **公式渲染**：数学表达式与化学式使用 LaTeX 行内格式（`$...$`）或独立公式格式（`$$...$$`）。不用 Unicode 上下标（如 $\Pi_6^6$）替代 LaTeX——不同渲染环境对 Unicode 上下标支持不一致，LaTeX 最可靠。
2. **化学式**：分子式用 `\mathrm{}` 排为正体（如 `$\mathrm{CO_2}$`），轨道符号同样正体（如 `$\mathrm{sp^3}$`）。变量斜体（如 $n$、$E$），单位正体（如 `$\mathrm{kJ/mol}$`）。
3. **单位统一**：全篇使用国际单位制（SI）或学科惯例单位，同一物理量前后单位不得混用。数值与单位间留一个空格（如 `$139\ \mathrm{pm}$`），且不换行。
4. **数据标注**：实验测量值标注有效数字位数，不随意增减精度。如某键长测得 $142\ \mathrm{pm}$ 不能写作 $142.0\ \mathrm{pm}$。

### 关于篇幅

复杂概念需要与其复杂度匹配的篇幅。宁可让读者"篇幅虽长但真正理解了"，也不要让他们"好像懂了但其实只拿到阉割版"。不要追求"三句话讲清楚 XX"——三句话说不清，就用三千字。

**暂停点**：初稿完成后，暂停请用户确认方向是否正确，再进入润色阶段（自主模式跳过，直接进入 Phase 4）。

## Phase 4：润色与记忆点强化

初稿解决"能否读懂"，润色解决"能否记住"。

### 记忆点强化手法

- **正反对照**：给正面例子的同时给反面例子或常见误解。只有正面案例的科普容易读过即忘。
- **意外转折**：在读者以为自己理解了时，引入一个反直觉的事实或视角。
- **具象锚点**：用具体场景、数据或故事作为记忆的"挂钩"，避免只有抽象论述。
- **渗透式升华**：深刻洞察分散在前文论证中，结尾收束点亮线索，而非结尾突然拔高。

### 修辞纪律（写作期护栏，核查期见 Phase 5 第 6–13 项）

- **密度优先**：内容密度优先于修辞密度。每个比喻/排比都自问——删掉它意思是否受损？不受损则删。
- **禁止手法**：不搞"未解之谜"式悬念主义；不滥用引号、冒号、破折号；不在缺乏证据时暗示"科学无法解释"。
- **禁止拟人化**：不给粒子/场/系统赋予意图、策略或选择能力。"电子为了更稳定而离域"是目的论倒装，应改为"离域态的能量低于定域态，所以体系自然处于离域态"。
- **禁止模型实体化**：不把理论模型写成原子内部发生的物理过程。杂化、分子轨道等是数学工具，不是原子的内部装修。
- **禁止比喻堆叠**：一个核心概念只用一个比喻体系，全篇比喻体系不超过两个且必须兼容。
- **历史轶事审慎**：科学史叙事区分"有文献支撑的史实"与"广泛流传但未经严格考证的轶事"，后者必须标注不确定性。
- **数字需有参照系**：抛定量数据必须提供数量级坐标让读者感知大小。孤立数字是噪声，有参照系的数字才是信息。
- **结尾不许浪漫化模型**：不把理论模型升格为分子的"灵魂"或"本质"。模型是工具，结尾应回到现象或问题本身。

## Phase 5：自查与交付

完成润色后，加载 `references/writing-guidelines.md`（13 条）与 `references/rhetoric-discipline.md`（8 条）逐项核对。以下 19 项自查，**每条必须过关**方可交付。

**结构与内容检查**：
1. **术语剥离测试**：将所有专业术语替换成大白话，核心观点是否依然成立且有洞见？
2. **增量测试**：是否有连续两句在说同一件事？
3. **闭环测试**：开头提出的问题，结尾是否回应了？
4. **信源测试**：每个事实性陈述是否有出处？信源等级是否达标？
5. **记忆点测试**：读者读完后能否复述出至少一个核心观点？

**修辞防殖民检查**（核心）：
6. **拟人化扫描**：全文搜索——粒子/场/系统是否被赋予意图、选择或策略？如有，改为因果条件式描述。
7. **比喻一致性检查**：用了几个比喻体系？是否彼此兼容？每个比喻是否标注失效边界？
8. **模型实体化检查**：理论模型（杂化、轨道、能带等）是否被写成原子内部发生的物理过程？如有，补上"这是描述框架"的提示。
9. **目的论检查**：是否存在"为了……所以……"式因果倒装？物理因果必须写成"A 条件导致 B 结果"，而非"B 为了 A"。
10. **历史叙事检查**：科学史故事是否区分有据史实与未证轶事？有无把轶事当确凿事实？
11. **判据精确性检查**：规则/判据/条件是否给出精确表述而非模糊口诀？若对目标读者过专，至少在注脚或括号内给完整形式。
12. **定量参照系检查**：每个数值是否有参照系？孤立数字必须补充比较对象。统计/数据题材还须补：**相对值是否给了绝对基线？群体统计量是否错当个体概率？**（见 `references/rhetoric-discipline.md` 规则 6 统计追加条款）
13. **结尾模型自觉检查**：结尾是否把理论模型升格为本体/灵魂/本质？如有，改回现象或问题层面收束。

**公式、单位与数据核查**：
14. **公式渲染检查**：所有数学表达式与化学式是否用 LaTeX 正确书写？不同渲染环境下能否正常显示？Unicode 上下标是否已替换为 LaTeX？
15. **单位一致性检查**：同一物理量前后单位是否统一？数值与单位间是否有空格？是否使用 SI 或学科惯例单位？
16. **数据准确性检查**：每个定量数据是否经至少两个独立权威信源交叉验证？是否存在"张冠李戴"？数据引用是否与原始文献一致？**自构的示意数字须显式标注"示意/非引自文献"，不得伪装成实测信源。**

**终稿精修预检**（Phase 6 执行前先识别问题）：
17. **冗余标点扫描**：全文是否存在不必要引号、破折号或冒号？去掉后语义是否仍清晰？
18. **术语标注完备性**：专业术语首次出现是否附英文原文？人名首次出现是否附英文原名？是否只在首次标注？
19. **术语一致性预检**：同一概念是否全篇使用同一译名？是否有不同中文表述混用指代同一事物？

### 产出物规范（交付结构）

终稿统一包含以下部分，顺序固定：

1. **标题**
2. **正文**（按 Phase 3 结构原则组织）
3. **核心记忆点**（1–2 句，读者读后应能复述的要点）
4. **信源与延伸阅读**（ numbered list，每条含：作者/机构、标题、出处、年份；标注信源等级 1–4）

### QA 自检报告模板

交付时附一份自检报告（自主模式必需，交互模式建议），格式：

```

- 目标读者：……
- 篇幅：…… 字
- 素材等级：一手/综述/权威媒体/信源不足(标注处)

| # | 自查项 | 结果 | 说明 |

```

自查通过后，进入终稿精修。

## Phase 6：终稿精修

自查解决准确性与逻辑，终稿精修解决文面整洁度与术语规范。这是交付前最后一道工序。

### 标点清理

1. **去除不必要的引号**：去掉后语义不产生歧义就去掉。引号只用于真正引用或确有必要标示的非常规用法，不用于强调、不包裹日常词汇、不制造语气效果。
2. **去除不必要的破折号**：破折号只用于真正解释说明或话语中断，不替代逗号或制造节奏感。能用逗号或句号断开就不用破折号。
3. **去除不必要的冒号**：冒号只用于列表引出或严格提示关系，不用于句中制造停顿。尤其避免"……的是："这类用法。

### 术语与专名规范

4. **英文术语标注**：专业术语首次出现时，中文表述并在括号内附英文原文。如"离域能（delocalization energy）""分子轨道（molecular orbital）"。后续不再重复。
5. **人名英文标注**：外国人名首次出现时括号内附英文原名。如"门捷列夫（Mendeleev）""拉瓦锡（Lavoisier）"。后续不再重复。
6. **术语一致性检查**：同一概念全篇必须使用同一译名，不得交替使用不同中文表述指代同一事物。如全文统一用"离域 $\pi$ 键"，不能时而"大 $\pi$ 键"时而"离域 $\pi$ 键"时而"共轭 $\pi$ 键"（除非行文中明确解释不同译名关系）。

### 操作要点

- 标点清理与术语标注逐段执行，不要跳读。
- 术语标注只做一次：首次出现，后续不重复。
- 若术语已有广为人知的英文缩写（如 DNA、RNA），无需再标英文全称。
- 避免用俗语、成语或网络梗替代精确表述（如"不三不四"式形容会削弱科学性）。通俗靠类比与算例，不靠俚语。

精修完成后，将终稿与 QA 报告一并交付用户。

## 多轮修改

用户可能要求修改特定部分。按修改类型采取不同策略：

- **事实性修正**：重新检索原始信源，确认后修改。
- **通俗度不够**：执行术语剥离测试，找出仍偏学术的段落重新转译。
- **记忆点不足**：在对应段落增加正反对照或具象锚点。
- **结构调整**：重新审视主次分配与逻辑闭环，必要时重写。
- **修辞殖民修正**：若读者指出拟人化/目的论/比喻堆叠等问题，参照 `references/rhetoric-discipline.md` 对应条目修改。
